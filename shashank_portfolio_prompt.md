### Copy Principles
- **Client-first language**: Replace "I am / I do" with "You get / I help you"
- **Specific over vague**: Replace "startups" with "early-stage SaaS / D2C / creative founders"
- **Results over process**: Show outcomes, not just deliverables
- **Conversational but confident**: Warm tone, no jargon

### Technical Recommendations
- Add Open Graph meta tags (title, description, image) for link previews
- Add a favicon that matches brand (SHAS-LAB logomark)
- Ensure mobile responsiveness — especially the Works grid
- Add Google Analytics or Plausible to track which pages convert

## REDESIGN AESTHETIC BRIEF

If rebuilding from scratch, maintain these visual rules:

```
BACKGROUND     #0A0A0A (near-black, not pure black)
TEXT PRIMARY   #FFFFFF
TEXT MUTED     #888888
ACCENT         #FFFFFF (bold weight as accent)
FONT DISPLAY   Current heavy sans-serif — keep it
FONT BODY      Light weight version of same, or neutral serif for body copy
GRID           12-column, generous gutters
SPACING        Generous — let content breathe
IMAGERY        High contrast, editorial photography only
HOVER STATES   Subtle: opacity shift or underline — never color change
```

**Do NOT add:**
- Colorful gradients
- Animations beyond subtle transitions
- Stock photography that isn't yours
- Generic icon sets
- Purple/blue AI-tool color schemes
