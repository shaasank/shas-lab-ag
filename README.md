# SHAS-LAB Portfolio

This is the personal portfolio website for SHAS-LAB (Shashank), featuring a showcase of works, background information, and contact details.

## Project Structure

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui

## Getting Started

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```

## Features

-   Responsive Design
-   Curated Animations (GSAP / Framer Motion equivalent)
-   Clean & Modern UI
